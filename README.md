## How to run on GitHub Pages

1. Create new repo on GitHub: e.g., `noa-website`
2. Upload `index.html` to repo root (drag & drop)
3. Go to Settings > Pages
4. Source: Deploy from branch: `main` / root
5. Save - your site will be live at https://yourusername.github.io/noa-website/

## Custom Domain (optional)
